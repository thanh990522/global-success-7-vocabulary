# Global Success 7 Vocabulary

A lightweight learning hub for **Global Success 7** vocabulary, organized into 12 units.

## Features
- 12 unit navigation
- **Learn Vocabulary**: opens/embeds the corresponding Loigiaihay vocabulary source page
- **Flashcards**: opens/embeds the corresponding Loigiaihay vocabulary-practice page
- Student progress saved locally in the browser
- Responsive desktop/mobile interface
- Fallback **Open source** button when a third-party page blocks iframe embedding

## Content policy
This repository does **not** re-host the original Loigiaihay images, audio files, or example text. Those materials remain served from their original webpages. This preserves source fidelity while avoiding redistribution of third-party assets.

## GitHub Pages
This is a static site. Publish the repository root (`main` branch / root folder) with GitHub Pages to use it as a public learning website.
