# Global Success 7 Vocabulary

Interactive vocabulary learning site for **Global Success 7**, organized into all 12 units.

## Current app
- 12-unit navigation
- Native vocabulary cards stored directly in the repository
- IPA + part of speech + Vietnamese meaning
- Newly written simple example sentences
- US-English browser speech pronunciation for every card
- Interactive flip flashcards
- Previous / Next / Shuffle controls
- **I know it / Again** memory tracking per unit
- Search by English word, Vietnamese meaning or word type
- Unit completion progress saved with `localStorage`
- Responsive desktop/mobile layout
- Full-source reference button for each supplied Loigiaihay unit page

## Files
- `index.html` — application shell
- `styles.css` — responsive cartoon-style interface
- `data.js` — vocabulary data by unit
- `app.js` — vocabulary, speech, flashcard and progress logic
- `.nojekyll` — GitHub Pages compatibility

## Source/content note
The app does not re-host Loigiaihay's original images, audio files or example sentences. Source pages remain linked for reference. Native example sentences in this repository are newly written for classroom practice, while pronunciation is generated by the learner's browser speech engine.

## GitHub Pages
This is a static site. Publish the repository root from the `main` branch using GitHub Pages to use it as a public learning website.
